# Frontier World | 前沿之境

Frontier World 的公开官网。当前版本围绕三个动作展开：观察变化、共同实践、开放成果。

## 本地开发

需要 Node.js 22.13 或更高版本。

```bash
npm ci
npm run dev
```

访问 `http://localhost:5173`。

## 验证

```bash
npm run check
```

## Cloudflare 部署

```bash
npm run deploy
```

生产域名：`frontierworld.ai`。

## 品牌资产

- `public/passage-mark-blue.svg`：浅色背景主标
- `public/passage-mark-white.svg`：蓝色或深色背景反白标
- `public/favicon.svg`：浏览器图标

当前使用 The Passage 6.1 A / 收束。不可镜像、旋转、拉伸或增加渐变、描边、发光与附加图形。
